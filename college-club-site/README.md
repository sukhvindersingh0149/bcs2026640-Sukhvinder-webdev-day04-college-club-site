# Campus Connect College Club

A responsive four-page college club website built with HTML and CSS. No framework or build step needed.

## Pages

- `index.html` - club introduction and calls to action
- `about.html` - club story and event table
- `registration.html` - student registration and volunteer forms
- `contact.html` - contact details and message form

## Preview

Open `index.html` in a web browser. Forms use `action="#"`, so nothing is sent to a server.
